# FJSP_MA_RE_dataset

考虑可再生能源的柔性作业车间机器与AGV集成调度算例数据。

## 数据文件

[FJSP_MA_RE_dataset.docx](FJSP_MA_RE_dataset.docx)包含25个算例EX01—EX25的详细数据，包括工件、工序、机器与AGV数量、各工序可选加工机器及相应的加工时间、车间栅格规模、机器位置及装卸点位置。

EX01—EX05、EX06—EX15和EX16—EX25分别为小、中、大规模算例。

## 算例来源

参考Homayouni和Fontes整理的柔性作业车间生产与运输联合调度基准算例构造测试算例，在原始加工数据的基础上补充车间栅格规模、AGV数量、机器位置及装卸点位置。
